# DEARLY

한 번의 초대, 오래 남을 마음.

DEARLY는 디자인 선택부터 사진 배치, 초대 문구 작성, 실시간 미리보기까지 한 화면에서 구성하는 모바일 청첩장 프로젝트입니다.

**운영 사이트:** https://wv1786969114656754.zaemit.ai/

## 이 저장소의 범위

2026년 9월 27일 운영 사이트에서 확보한 프런트엔드 스냅샷과 직접 작성한 편집기 코드, 글씨 디자인 변경 전 백업을 보관합니다. Zaemit 전체 서버 소스 또는 독립 배포 패키지는 아닙니다. 사이트를 수정해도 이 저장소에 자동으로 동기화되지는 않습니다.

## 주요 구성

- 디자인 및 본문 템플릿 선택과 휴대폰 형태의 실시간 미리보기
- 사진 드래그 앤 드롭, 확대와 위치 조절
- 이름, 예식 일시, 장소, 초대 문구 편집
- 명조·손글씨·고딕 글씨체 비교와 선택
- 브라우저 임시 저장, 공유 및 HTML 내보내기를 위한 편집기 코드
- 오시는 길, 계좌, 참석 여부, 축하 메시지와 공유 영역

## 파일 안내

| 경로 | 내용 |
| --- | --- |
| `site/index.html` | 현재 공개 페이지의 HTML·스타일·스크립트 스냅샷 |
| `src/footer.js` | 현재 반영된 청첩장 편집기 스크립트. 플랫폼의 footer 컴포넌트에 저장되어 있음 |
| `src/typography/` | 글씨체 선택 모듈 및 스타일 원본. footer.js에 통합된 부분의 편집용 사본 |
| `backups/before-typography/` | 이번 글씨 디자인 수정 이전 백업 |
| `docs/ROLLBACK.md` | 재밋 복원 지점과 복원 시 주의사항 |
| `docs/external-assets.json` | 공개 HTML에서 확인된 외부 자산 참조 목록 |

`src/typography/`의 파일은 독립 앱 진입점이 아니며, 원본 편집기 내부 상태와 함께 작동합니다. 편집 시 `src/footer.js`와 일관성을 유지해야 합니다.

## 실행과 이전 시 참고

실제 동작 확인은 운영 사이트에서 할 수 있습니다. `site/index.html`은 보존용 스냅샷으로, 단순히 GitHub Pages에 올린다고 같은 서비스가 완성되는 구조가 아닙니다.

- `/weven_service/` 경로의 런타임과 스타일은 재밋에서 제공합니다.
- 로그인과 계정 저장 등 서버 기능은 재밋의 인증·데이터 API에 의존합니다. 서버 구현과 운영 데이터는 이 저장소에 포함되지 않습니다.
- 사진과 일부 글꼴은 외부 URL을 참조하며, 원본 이미지 파일 전체가 포함된 것은 아닙니다.
- 별도 호스팅으로 이전하려면 위 자산 경로, 인증, 저장 API 및 공유 동작을 새 환경에 맞춰 연결하고 검증해야 합니다.

## 확인한 항목

글씨체 변경 시 미리보기의 실제 이름과 본문 반영, 새로고침 후 선택 복원, 390px 모바일 화면의 가로 넘침 여부를 확인했습니다. 이 기록은 해당 변경의 검증 범위이며 전체 서비스의 모든 기능 검증을 의미하지 않습니다.

## 변경 복원

이번 글씨 디자인 변경 직전 재밋 복원 지점은 **105**입니다. 이후 다른 변경이 생겼다면 컴포넌트 전체 복원 전에 변경 내역을 비교해야 합니다. 자세한 절차는 `docs/ROLLBACK.md`를 참고하세요.
